# Datasets

The repository does not include raw network files. Download the six empirical
edge lists used by the experiments and place them in this directory with the
following names:

| File | Source |
| --- | --- |
| `CA-HepPh.txt` | [SNAP: CA-HepPh](https://snap.stanford.edu/data/ca-HepPh.html) |
| `Email-Enron.txt` | [SNAP: Email-Enron](https://snap.stanford.edu/data/email-Enron.html) |
| `cit-HepTh.txt` | [SNAP: cit-HepTh](https://snap.stanford.edu/data/cit-HepTh.html) |
| `bio-dmela.txt` | [Network Repository: bio-dmela](https://networkrepository.com/bio-dmela.php) |
| `Wiki-Vote.txt` | [SNAP: Wiki-Vote](https://snap.stanford.edu/data/wiki-Vote.html) |
| `tech-as-caida.txt` | [Network Repository: tech-as-caida](https://networkrepository.com/tech-as-caida.php) |

The loaders convert each network to a simple undirected graph, remove
self-loops, and retain the largest connected component (LCC) before analysis.
The synthetic ER, WS, and BA networks are generated by the scripts and need no
download.
